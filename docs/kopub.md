# KoPub World 사용 안내

확인일: 2026-09-06

스타일 패널에서 KoPub World 바탕·돋움을 선택할 수 있습니다. CSS `local()`로 사용자 기기에 설치된 원본 서체를 찾습니다. 폰트 파일은 이 저장소와 배포 서버에 포함하지 않습니다. 기기마다 설치해야 하며, 설정 JSON을 공유해도 글꼴 파일은 전달되지 않습니다.

설치되지 않았거나 브라우저에서 로컬 글꼴 접근이 제한되면 바탕은 나눔명조, 돋움은 Noto Sans KR로 표시합니다. 패널에서 설치 여부를 확인하고 공식 배포처로 이동할 수 있습니다. 설치 후 새로고침하세요. 기본 서체와 기존 프리셋은 그대로 유지합니다.

## 확인한 자료와 판단

- [한국저작권위원회 공유마당: KoPub World 바탕 M](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200195&wrtSn=13287215), [돋움 M](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200195&wrtSn=13287212): 문화체육관광부와 한국출판인회의의 지적재산권, 명시된 약관에 따른 무료 사용, 사전승인 없는 수정·변형·임대·재판매 제한, 별도 KoPub 약관 참조가 안내되어 있습니다.
- [공유마당 2021년 인기 글꼴 공지](https://gongu.copyright.or.kr/gongu/bbs/B0000001/view.do?menuNo=200038&nttId=4156&pageIndex=)는 KoPub World를 공공누리 제1유형으로 표시합니다. [공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do)은 출처 표시를 조건으로 온라인 공유와 상업적 이용을 허용합니다. 다만 현재 개별 배포 페이지의 별도 약관 안내와 적용 관계를 확정하지 못했습니다.
- [한국출판인회의 공식 안내](https://www.kopus.org/biz-electronic-font2)와 공식 약관 PDF는 확인 당시 HTTP 403으로 열리지 않았습니다. 서버 탑재 시 별도 승인을 요구하는 이전 안내와 상충 여부를 해소할 수 없으므로, 템플릿 전체에 웹폰트 재배포가 허용된다고 단정하지 않습니다.

따라서 이번 구현은 로컬에 설치된 서체를 참조하는 범위입니다. 웹폰트 파일을 서버에 제공하려면 권리자의 현재 웹 임베딩·재배포 조건을 확인한 뒤 해당 조건에 맞게 별도로 추가해야 합니다. 저장소의 MIT 라이선스는 KoPub 글꼴에 적용되지 않습니다. 서체 설치·출판 이용자는 공식 배포처의 사용 조건을 따라야 합니다.
