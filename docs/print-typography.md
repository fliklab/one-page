# 종이책 판형과 본문 설정

확인일: 2026-09-06. 아래 설정은 출판 가이드와 공개된 편집 사례를 참고해 이 템플릿에 맞게 정한 시작값입니다. 출판 시장 전체의 서체 사용량 순위나 모든 책에 적용되는 표준은 아닙니다.

## 판형

- 국판 A5: 148 × 210 mm. 기본값이며 소설·시·수필에 쓰이는 판형입니다.
- 사륙판: 128 × 188 mm. 시·에세이용 작은 책에 사용할 수 있습니다. JIS B6의 128 × 182 mm와 구분합니다.
- 신국판: 152 × 225 mm. 인쇄사에 따라 152 × 224 mm 등 차이가 있으므로 제작 업체의 규격을 최종 확인합니다.
- 사륙배판 / JIS B5: 182 × 257 mm. 교재·실용서용 선택지입니다.
- ISO B5: 176 × 250 mm. 기존 `b5` 키는 이 규격으로 유지합니다.
- A6: 105 × 148 mm, A4: 210 × 297 mm, 정사각: 180 × 180 mm.

출처: [바른북스 분야별 출판 가이드](https://www.barunbooks.com/m/html/dh/guide02_01), [열림프린팅 제작 사이즈 가이드](https://www.yeolimprinting.co.kr/guide/guide1_1/).

## 서체

명조·바탕 계열을 긴 글의 기본 선택지로, 고딕 계열을 실용서 선택지로 제공합니다. 기본은 나눔명조입니다. Noto Serif KR(본명조 계열)과 Noto Sans KR(본고딕 계열)을 추가하고, 기존 고운바탕·프리텐다드를 유지했습니다. 웹폰트는 원 배포처의 CSS를 통해 불러옵니다.

- [네이버 나눔글꼴 안내](https://hangeul.naver.com/download): 나눔명조와 사용 조건.
- [Adobe Source Han Serif 소개](https://source.typekit.com/source-han-serif/): 인쇄와 화면 용도를 함께 소개하는 오픈소스 명조 계열.
- [Adobe의 Source Han Serif / Noto Serif CJK 개발 설명](https://ccjktype.fonts.adobe.com/2017/04/source-han-serif-history-development.html): 두 이름으로 배포되는 서체 계열의 배경.

KoPub World 바탕·돋움을 기기 설치형 선택 항목으로 제공합니다. 사용 조건 조사와 적용 범위는 [KoPub 사용 안내](kopub.md)를 참고하세요.

## 크기, 행간, 여백

기본값은 **국판 · 나눔명조 · 본문 11pt · CSS 줄간격 175% · 네 변 여백 18mm**입니다.

| 설정 | 판형 | 본문 | 줄간격 | 여백 |
| --- | --- | --- | --- | --- |
| 에세이·수필 | A5 | 나눔명조 11pt | 175% | 18mm |
| 소설·인문 | 신국판 | Noto Serif KR 10.5pt | 170% | 18mm |
| 작은 에세이·시집 | 사륙판 | 나눔명조 10.5pt | 180% | 15mm |
| 실용서·교재 | JIS B5 | Noto Sans KR 11pt | 165% | 20mm |
| 큰 글씨 | A5 | 나눔명조 14pt | 170% | 16mm |

10.5pt와 170%는 [한국정책학회 원고 집필요강](https://kpolicy.or.kr/homepage/boardMedia/172776)의 KoPub바탕 본문 편집 사례에서도 확인할 수 있습니다. 이는 학술지 사례이며, 일반 단행본의 의무 규격이나 시장 평균으로 간주하지 않습니다. 위 조합과 여백은 이 웹사이트를 위한 편집 판단입니다. 한글(HWP)의 줄간격 백분율과 브라우저 CSS `line-height`는 계산 방식이 같지 않으므로 동일한 조판 결과를 보장하지 않습니다.

## 화면, 단위와 호환성

- 판형과 여백은 mm, 본문 크기는 pt, 행간은 %로 표시합니다.
- 가상 종이의 크기와 본문은 동일한 환산 기준을 사용합니다: 1in = 25.4mm = 72pt = 96 CSS px.
- 기존 JSON의 `fontSize`, `margin`, `spineWidth`는 호환성을 위해 CSS px를 유지합니다. 설정 복사 결과의 `print`에 pt/mm 환산값, `paper`에 숫자형 가로·세로 mm를 함께 제공합니다.
- 기존 기본 조합(A5 / 고운바탕 / 18px / 1.9 / 여백 56px)만 새 기본 조합으로 한 번 바꿉니다. 직접 조정한 글자 크기, 서체, 판형과 테마, 책 내용은 유지합니다. `typographyVersion: 2`로 재적용을 방지합니다.
- 모니터의 실제 물리 크기를 보정하는 기능은 아닙니다. 독서 화면은 가용 공간에 맞춰 종이 전체를 축소합니다. 작은 화면에서는 Edit 문서 보기로 읽거나 큰 글씨 설정을 사용할 수 있습니다.
- UI 글자 크기와 종이의 활자 크기는 별개입니다. 종이 본문의 10.5~11pt는 이번 인쇄 규격 요청에 따른 값이며, 설정 패널은 화면용 크기를 사용합니다.
- 현재 미리보기는 인쇄용 PDF가 아닙니다. 재단 여유, 안쪽 제본 여백, 도련, CMYK, 이미지 해상도, 실제 책등 두께는 제작 업체와 별도로 확정해야 합니다.
